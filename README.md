# Predicting Insurance Costs & Heart Disease — EDA & Data Preprocessing

This project focuses on **Exploratory Data Analysis (EDA), data cleaning, and data preprocessing** for two real-world machine learning problems:

- 🏥 **Heart Disease Prediction** — analyzing patient health and clinical features to prepare the dataset for predicting the presence of heart disease.
- 💰 **Insurance Cost Prediction** — analyzing demographic and lifestyle-related factors to prepare the dataset for predicting medical insurance costs.

The project demonstrates the complete data preparation workflow, including **data inspection, missing-value analysis, duplicate detection, outlier analysis, statistical analysis, visualization, categorical encoding, feature scaling, and preparation of data for machine learning models**.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Key Areas Covered

- Data understanding and inspection
- Exploratory Data Analysis
- Missing-value handling
- Duplicate detection and removal
- Outlier detection and treatment
- Univariate and bivariate analysis
- Correlation analysis
- Categorical feature encoding
- Feature scaling
- Train-test split
- Machine-learning-ready dataset preparation
